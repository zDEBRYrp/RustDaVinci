# RustDaVinci

Автоматический художник для табличек в игре Rust (Facepunch): берёт картинку,
квантует её в палитру Rust и рисует на холсте кликами мыши. Форк
[alexemanuelol/RustDaVinci](https://github.com/alexemanuelol/RustDaVinci),
переработанный под актуальный клиент: Pillow ≥ 10, один UI, HEX-ввод цвета.

> ⚠️ **Дисклеймер.** Автокликеры могут нарушать правила серверов, провоцировать
> кик/бан и конфликтовать с EAC. Используйте на свой риск, лучше — на своём
> сервере. Проект не аффилирован с Facepunch.

## Возможности

- Загрузка картинки из файла (PNG/JPG/JPEG/GIF/BMP), по URL и из буфера обмена.
- Живое превью: ч/б режим, пропуск фона, лимит цветов (0 = авто).
- Квантование в палитру Rust 256 цветов через `Image.quantize()`:
  видимые/скрытые цвета, уровни прозрачности кисти, пропуск фона и своих цветов.
- Умный авто-отбор цветов: отсев шума < 0.2%, покрытие 99.5%, cap 64 цвета
  (или топ-N при заданном лимите).
- Рисование кликами или линиями (Shift-drag) — выбирается по оценке времени.
- Внешний HEX-режим: цвет вводится в поле HEX игры вместо кликов по палитре
  (координаты задаются в диалоге «Координаты HEX»).
- Пауза (F10) / пропуск цвета (F11) / отмена (Esc), настраивается.
- Рисование в фоне не блокирует интерфейс (рабочий `QThread`).
- Автопоиск панели инструментов через OpenCV + ручной захват холста.

## Требования

- Windows 10/11, Python 3.10–3.12.
- Зависимости — в `requirements.txt`, для разработки — `requirements-dev.txt`.

## Установка и запуск

```bat
git clone https://github.com/zDEBRYrp/RustDaVinci.git
cd RustDaVinci
pip install -r requirements.txt
python app.py
```

Тесты:

```bat
pip install -r requirements-dev.txt
python -m pytest tests -q
```

Сборка exe:

```bat
pip install pyinstaller
python build_script.py
```

## Как пользоваться

1. Загрузите картинку (FILE / URL / CLIP) — появится превью.
2. Настройте «Режим одного цвета», «Пропускать фон», лимит цветов.
3. Откройте «Настройки»: задайте область панели управления (`ctrl_*`),
   задержки кликов, кисть, горячие клавиши. Кнопка «Координаты HEX» —
   для внешнего HEX-поля (размер/интервал/прозрачность/HEX по скриншоту).
4. Нажмите «Начать рисование» → выделите холст drag-ом от левого верхнего
   угла к правому нижнему → подтвердите статистику.
5. Во время рисования: F10 — пауза, F11 — пропустить цвет, Esc — отмена.

## Структура

```
app.py                    точка входа (styled UI)
build_script.py           сборка exe через PyInstaller
lib/
  rustDaVinci.py          ядро: палитра, квантование, статистика, поток рисования
  rustPaletteData.py      палитра Rust (256 цветов)
  color_functions.py      hex<->rgb, ближайший цвет палитры
  captureArea.py          захват холста/точки (Windows)
  opencv_template/        шаблон для автопоиска панели
ui/
  views/main_styled.py    главное окно
  settings/               настройки (QSettings) + .ui
  dialogs/               захват области, координаты кисти/HEX, цвета
  resources/             иконки, кисти, gifs, скомпилированные ресурсы
tests/                   pytest: цвета, палитра, статистика
```

## Что починили в этом форке

- `ctrl_y` читался из ключа `ctrl_h` — панель уезжала по вертикали.
- Убрано приватное API Pillow (`image.im.convert`, `_new`/`_makeself`) —
  квантование через публичный `Image.quantize()`, работает на Pillow ≥ 10.
- `quantize_to_palette` больше не перезаписывает `org_img` (работал с копией).
- Фон скипается/заменяется по одной колоночной логике в `update_palette`
  и `update_skip_colors` (было расхождение шагов 64 vs 20).
- Guard от деления на ноль при `tot_pixels == 0` в прогрессе.
- Рисование вынесено в `QThread` — интерфейс не виснет, пауза через событие.
- Превью и буфер обмена без временных файлов в CWD (`temp_*.png` удалены),
  попиксельные циклы заменены на numpy.
- Один UI (`main_styled.py`): удалены `main.py`, `main_new.py`, `mainui*.py/.ui`,
  `app.pyw`, `test/`, `opencv_template/`-дубликат, `gartic`-ассеты, `convert_*.py`,
  `paint_settings_dialog.py`, `pyc`.
- Добавлены `requirements.txt`, `requirements-dev.txt`, `.gitignore`, `tests/`,
  переписан `build_script.py` под `app.py`.
